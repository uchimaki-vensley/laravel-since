# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/uchimaki-vensley/laravel-since/security/advisories/new).
You will get a response as soon as possible.

脆弱性は公開の Issue ではなく、上記の非公開の報告フォームから報告してください。

## Scope

This repository builds a static website from the public source code of the Laravel framework.
It has no user accounts and stores no personal data. See [docs/security.md](docs/security.md)
for the threat model and the protections in place.
